## Hard constraints
- Grid only.
- No Flexbox.
- Reuse existing classes before new ones.
- If new classes are required, they belong in the owning component or page stylesheet.
- No inline style.
- No invented props or custom tokens.
- Use house vocabulary only.
- Guard defs with ?:.
- Ask before adding new patterns.
