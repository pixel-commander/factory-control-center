# Pick-a-Pack Index

This folder contains curated task bundles built from the core skills and rules library.

## Available packs
- ui-generation
- code-review
- app-architecture
- demo-authoring
- strict-house-compliance
- docs-keeper

## Use pattern
Choose a pack that matches the task, then pull the relevant files from skills/ and rules/ as needed.

## Rule of thumb
Keep the bundle narrow. Use only the pieces needed for the specific job.
