# Core runtime skills

Use these when working in the chat runtime and agent environment.

- Use the available built-in skills when the task calls for them.
- Prefer tool-driven actions over speculative reasoning.
- Keep the task scoped to the current request.
- When a skill is relevant, invoke it immediately.
- Do not invent missing capabilities; use the available toolset.
- Ask for clarification when the choice materially changes the implementation.
