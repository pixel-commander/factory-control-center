# UI build skills

Use these when generating or revising UI work.

- Use CSS Grid only.
- Use the canonical grid system from grid.css in HOUSE_CSS (per PATHS.txt).
- Use theme tokens from theme.css in HOUSE_CSS.
- Prefer existing atoms before new CSS.
- Reuse existing classes before creating a new one.
- If a new class is truly necessary, keep it in the owning component or page CSS file.
- Do not use inline visual style props.
- Keep layout patterns consistent with the house system.
