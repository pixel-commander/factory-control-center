# Quick review checklist

Before finishing any UI task, confirm:

- No Flexbox used
- No inline styling used
- Existing classes were reused before new ones were created
- New classes, if any, were added only to the owning component or page stylesheet
- No ad hoc custom classes were invented in shared/global CSS
- Only approved grid utilities used
- Props match the house vocabulary
- Definitions are guarded with ?:
- URL-driven state is preferred where appropriate
- Component structure follows the template pattern
- The work matches the project’s house rules
