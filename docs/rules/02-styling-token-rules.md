# Styling and token rules

- Use tokens from theme.css in HOUSE_CSS (per PATHS.txt).
- Use atoms from ATOMS before creating any new CSS.
- Reuse existing class names before making a new one.
- If a new class is needed, put it in the owning component or page CSS file.
- No inline style props for visual design.
- Do not invent new color, spacing, or visual tokens without approval.
- No custom visual classes unless they are a house-approved atom or token.
- Keep styling consistent with the existing design system vocabulary.
