# Naming and structure rules

- .tsx files are PascalCase.
- .css files are kebab-case.
- functions are camelCase.
- component and dashboard folders are PascalCase (the stamps enforce this).
- atom folders are kebab-case, organized by kind (containers, buttons).
- component file names are PascalCase.
- Keep component structure aligned with the repo template pattern.
- Pages live under PAGES (per PATHS.txt) with kebab-case folder names and PascalCase file names.
- If a new class is needed, keep it local to the owning component or page stylesheet.
