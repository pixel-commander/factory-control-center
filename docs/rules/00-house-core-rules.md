# House core rules

This is the foundation for any UI work.

- Use CSS Grid only.
- No Flexbox.
- Reuse existing classes before creating any new class.
- If a new class is required, it must live in the relevant component or page stylesheet, not in a shared global stylesheet or shared utility.
- Do not invent custom layout classes outside the canonical grid system.
- Use house tokens and atoms before custom styling.
- If it is not an approved house pattern, ask for a new entry instead of inventing it.
- Keep decisions grounded in the project’s source of truth.
