USERSLIST
=========

The user shape as a LIST - built file for file on the TasksList
reference (its README documents the whole pattern).

- Table word: 'users' - PLURAL, the same word UserForm writes (the
  lane is not one convention; kept exactly).
- UserElement is the row: name on the left, muted title on its own
  line - the user shape carries no second short word, so the right
  column stays empty rather than forcing one. css\user-item.css is the
  element's atom - the licensed home for user-specific grid work.
- Search word lives inside the component; click reports up only; the
  demo mounts the list live and is db-safe (lists only read).
