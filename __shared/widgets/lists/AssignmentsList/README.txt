ASSIGNMENTSLIST
===============

The assignment shape as a LIST - built file for file on the TasksList
reference (its README documents the whole pattern).

- Table word: 'assignment' - the same word AssignmentForm writes, so
  what the form saves is what this list draws.
- AssignmentElement is the row: name on the left, status on the right,
  muted title on its own line. css\assignment-item.css is the
  element's atom - the licensed home for assignment-specific grid work.
- Search word lives inside the component; click reports up only; the
  demo mounts the list live and is db-safe (lists only read).
