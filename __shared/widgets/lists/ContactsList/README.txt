CONTACTSLIST
============

The contact shape as a LIST - built file for file on the TasksList
reference (its README documents the whole pattern).

- Table word: 'contacts' - PLURAL, the same word ContactForm writes
  (the lane is not one convention; kept exactly).
- ContactElement is the row: name on the left, CITY on the right - a
  contact has no status, and the city is its one short domain word -
  muted title on its own line. css\contact-item.css is the element's
  atom - the licensed home for contact-specific grid work.
- Search word lives inside the component; click reports up only; the
  demo mounts the list live and is db-safe (lists only read).
