COURSESLIST
===========

The course shape as a LIST - built file for file on the TasksList
reference (its README documents the whole pattern).

- Table word: 'course' - the same word CourseForm writes, so what the
  form saves is what this list draws.
- CourseElement is the row: name on the left, status on the right,
  muted title on its own line. css\course-item.css is the element's
  atom - the licensed home for course-specific grid work.
- Search word lives inside the component; click reports up only; the
  demo mounts the list live and is db-safe (lists only read).
